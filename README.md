# 小米保固查詢 APP(零費用版)

## 運作方式
- GitHub Actions 每週一台灣時間 06:00 自動執行 `scraper.js`,讀取 mi.com/tw/service/exchange/ 全部類別(新類別會自動納入),有變動就更新 `public/data.json`,並發佈到 GitHub Pages。
- APP 是靜態網頁(可安裝到手機)。按「↻ 更新」= 重新下載最新 data.json,有新產品會提示並標「新」。
- 全程不呼叫 AI,不耗 Claude token,公開 repo 無任何費用。

## 部署(一次性,約 10 分鐘)
1. 註冊 GitHub,建立**公開** repo,把檔案分 3 次上傳(含 .github 資料夾;網頁一次最多 100 個檔案,所以照片已分成 photos-1、photos-2 兩個資料夾,發佈時會自動合併回 public/img)。
2. Settings → Pages → Source 選 **GitHub Actions**。
3. Actions 頁 → 「更新小米保固資料並發佈」→ Run workflow,首次執行後取得網址 https://<帳號>.github.io/<repo>/
4. 看 Actions 日誌:若出現「抓取失敗,沿用舊資料」警告,代表 GitHub 機器連不上 mi.com(被擋或排隊),內建的 2026-11-14 資料仍可使用。

## 安裝到手機
iPhone:Safari → 分享 → 加入主畫面。Android:Chrome → 安裝應用程式。

## 尊享服務
資料來源 https://www.mi.com/tw/support/terms/vipservice/ 。內建資料是 2026-11-14 整理的摘要,其中 Xiaomi 13T、13 Ultra、12 系列、POCO F9、Mi Note 10 當時讀取失敗,只顯示官網連結;自動更新成功後會改顯示頁面原文行。有新機型頁加入目錄時會自動出現並提示。

## 國際聯保
來源為手機售後頁「國際聯保服務」區塊的機型連結。機型旁顯示「國際聯保」標籤,也可用「🌐 國際聯保」篩選。Xiaomi 15 Ultra 與 MIX Flip 內建資料讀取失敗,只顯示官網連結。

## 分項保固(主機/配件/耗材不同保固)
官網把同一產品的主機、電源線、耗材等拆成多列時,APP 會合成一張卡片,依序列出每一項的保固期、以換代修/維修標示。規則放在 data.json 的 `groups`(合併多列為一張卡)與 `shared`(螢幕、電視、路由器、攝影機共用的配件列)。備註中「項目 期限」格式(如 USB線 不保固)也會自動拆成分項。新增產品若沿用同樣表格寫法會自動套用;全新的拆分方式需補一筆 groups。「上門維修服務」等服務類型目前只有智慧淨水器有資料。

## Google 試算表(輔助資料來源)
**官網售後政策優先,表格為輔。** 每週自動抓取官網(免費);你改完表格,按 APP 的「更新」就會重新讀取官網資料與表格,讀不到時顯示上次成功的資料。更新鍵不能當場去官網抓,官網新出現的產品要等每週一的自動抓取後才會出現(也可在 GitHub 的 Actions 頁面手動按 Run workflow 立即抓取)。
**一次性設定:** 試算表右上角「共用」→「一般存取權」→「知道連結的任何人」→ 角色選「檢視者」。連結已寫在 `public/config.json`(`sheetUrl`),換表格時改這裡。
**分頁:** 「說明」(填寫說明,APP 不讀)、「目錄」(列出要讀的分頁名稱)、以及 12 個分類分頁(手機平板、耳機喇叭、手錶手環、電視螢幕投影、網路攝影機、智慧家庭、充電配件、清潔電器、廚房電器、空氣洗衣家電、個人護理旅行、生活週邊)。**新增分頁後,務必把分頁名稱加到「目錄」**,APP 才會讀到。
**欄位(每個分頁都一樣):** 類別、品牌、產品名稱、保固期限、保固方式(以換代修 / 維修)、分項保固、備註、相容型號、圖片網址、資料來源(官網 / 依類別推定 / 自行整理 / 待確認)。最後一欄「官網原文」只是參考,APP 不讀。
**規則(官網優先):**
- 官網政策頁已有的產品:保固期限、分項保固、保固方式、備註**一律以官網為準**,表格填不同的值不會覆蓋,只會列在 APP「🔎 每月檢查」的「官網與表格不一致」。表格只能替官網產品補:圖片網址、相容型號、品牌。
- 官網沒有的產品(新型號、台灣商城有賣但政策頁未列):以表格為準,產品名稱沒出現過就新增。資料來源填「依類別推定」或「待確認」會顯示對應標籤;填「已確認」或「官網」則不顯示標籤。
- 表格沒有「狀態/隱藏」欄(已取消);想移除某項產品,把那一列從表格刪掉即可。官網政策頁的通稱、台灣沒有的產品,由 `data.json` 的 `hide` 清單維持不顯示,要新增或取消請告訴維護者。
- 官網日後收錄了你補的型號,APP 自動改用官網資料,該列會出現在「每月檢查」的「官網已收錄,表格那列可以刪」。
- 類別填新名稱會自動出現新的分類按鈕(分頁只是方便整理,APP 的分類看「類別」欄)。
**每月檢查:** APP 的「🔎 每月檢查」整理四塊:官網與表格不一致、官網已收錄可刪的列、最近 35 天官網新增的產品(來自 data.json 的 changelog)、官網還沒收錄且保固未確認的補充項目。建議每月看一次。
**分項保固寫法:** 用「｜」分隔每一項,格式 `項目=期限`,可加 `@服務類型`、`#以換代修` 或 `#維修`。例:`主機=1年｜電源線=6個月｜濾心=無保修`、`淨水器主機=1年@上門維修服務`。
**相容型號:** 用「｜」分隔多個。**圖片網址:** 貼商品圖的完整網址。

## 隱藏項目
data.json 的 `hide` 清單列出不想顯示的官網列(已有逐款型號的通稱、台灣未販售的產品)。每週更新不會讓它們重新出現;要恢復只要從清單刪除。

## 外觀與系列分類
小米經典橘 + 科技簡約風,支援深色模式。手機平板、耳機喇叭、手錶三個類別會再分「Xiaomi / Redmi / POCO / 配件與其他」,依產品名稱開頭判斷(Xiaomi、小米、米家 → 小米;Redmi、紅米 → 紅米;POCO → POCO)。

## 保護機制
抓到筆數少於舊資料 70%、或單一類別少於一半 → 保留舊資料不覆蓋;官網排隊頁會自動重試 3 次。

## 產品圖片
售後頁沒有產品圖,預設顯示類別圖示。想加圖:在 public/images.json 填 {"產品名稱":"圖片網址"},下次更新自動套用。

## 本機預覽
npm install && npm start;手動抓取:npm run refresh


## 產品照片(本機小圖)

- 官網抓不到圖的型號,可把商城截圖裁成小圖放進 `public/img/`,並在 `data.json` 的 `photos` 以「產品名稱 → 圖片路徑」登錄。
- 優先順序:試算表「圖片網址」> 官網圖;官網圖載入失敗時自動改用本機小圖。
- 圖片為 176px webp,每張約 3–6KB。

`data.json` 的 `retired` 清單列出已改名或已拆分的舊名稱(例如「無線吸塵器4C」),表格裡殘留的舊列不會因此重新長出重複的卡片。
